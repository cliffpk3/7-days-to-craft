# 7 Days to Craft - atualizacoes pelo GitHub

## Para o criador do modpack

Execute `PUBLICAR-ATUALIZACAO.bat`, descreva a alteracao e aguarde o push terminar.

## Para os jogadores

Na primeira instalacao, instale Git for Windows, coloque `ATUALIZAR-7DTC.bat` dentro da pasta `versions\7-days-to-craft` e execute-o. Nas proximas atualizacoes, basta executar o mesmo arquivo novamente antes de abrir o jogo.

O atualizador preserva saves, opcoes pessoais, mapas do Xaero, waypoints, logs e dados locais.
